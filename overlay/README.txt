Apply the VGM files by copying `vgm_firmware/app/*` into the upstream
`video-game-module/app/` directory.

Install the Flipper app by copying `flipper_app/` to:
`flipperzero-firmware/applications_user/usb_text_writer/`.

The VGM firmware in this bundle is intentionally standalone and does not use
the official display/RPC application path.
